# 우리동물구조대

- `index.html` — 홍보용 홈페이지 (길고양이 중성화 TNR 안내)
- `dispatch.html` — 배차·동선 관리 앱 (시제품)

## 배차·동선 앱 (`dispatch.html`)

휴대폰 브라우저에서 바로 열어 쓰는 한 장짜리 웹앱입니다. 설치나 서버가 필요 없습니다.

1. **설정** 탭에서 구조대원 이름을 등록하고, 출발지(사무실·차고지)를 지도에 찍습니다.
2. **오더** 탭에서 `+ 새 오더`로 요청을 등록합니다.
   - 유형과 기본 단가 (설정 탭에서 변경 가능)
     | 유형 | 단가 |
     |---|---|
     | 포획틀 설치·수거 | 8,000원 / 회 |
     | 포획·병원 인계 | 9,000원 / 마리 |
     | 병원 방문 후 방사 | 8,000원 / 마리 |
   - 금액 = 단가 × 수량 (수량 기본 1)
   - 주소, 장소 메모, 수량, 요청자 연락처, 담당 대원, 메모
   - 지도를 눌러 위치를 찍으면 동선 정렬에 쓰입니다. (`위치 찾기`로 주소 검색도 가능)
   - 상태: 대기 → 배정 → 진행중 → 완료 (카드의 버튼으로 한 단계씩 진행)
3. **동선** 탭에서 날짜와 대원을 고르면 그날 갈 곳이 지도와 순서 목록으로 나옵니다.
   - `가까운 순 정렬`: 출발지부터 가까운 순서로 자동 정렬 (▲▼로 직접 조정 가능)
   - `길찾기`: 카카오맵 길안내로 연결
   - `오더 보내기`: 그날 동선을 글로 만들어 카톡·문자로 공유
4. **정산** 탭에서 월을 고르면 ‘완료’된 오더를 대원별·유형별로 합산합니다. `엑셀(CSV) 받기`로 상세 내역을 내려받을 수 있습니다.
   - 완료 처리할 때의 단가가 오더에 고정되므로, 나중에 단가를 바꿔도 지난 정산 금액은 바뀌지 않습니다.

### 현재 한계
- 데이터는 **그 기기의 브라우저에만** 저장됩니다. 대원끼리 실시간 공유는 안 되고, 오더는 `오더 보내기`로 카톡에 보내는 방식입니다. 기기를 옮길 때는 설정 → 내보내기/불러오기를 쓰세요.
- 거리 계산은 직선거리 기준이며, 실제 도로 경로는 카카오맵 길찾기를 이용합니다.
- 주소 검색은 무료 지도(OpenStreetMap)를 써서 한국 주소를 못 찾는 경우가 있습니다. 그럴 때는 지도에서 직접 눌러주세요.
